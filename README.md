# Calradia Troops

Every troop tree and encyclopedia unit page of Mount & Blade II: Bannerlord (with War Sails), in one
offline page: https://traxdata313.github.io/calradia-troops/

Fan-made and unofficial. The troop pictures, names and stats come from the game and belong to TaleWorlds
Entertainment. The page is built by a private generator from the game's own data; this repo only holds the result.
